# SEVA – Sustainable Ecology & Village Advancement

> **Empowering Grassroots Organisations Through Technology, Knowledge and Digital Transformation**

SEVA is a dedicated development support initiative headquartered in Ralegaon, Yavatmal, Maharashtra, India. We strengthen grassroots non-profits, voluntary organisations, and community development teams across India through need-based digital transformation, integrated Management Information Systems (MIS), data governance, and institutional capacity building.

---

## 🌾 Core Focus Areas
- **Digital Capacity Building:** Hands-on training for ground staff, field coordinators, and community leaders.
- **MIS & Data Management:** Custom cloud database schemas, field data collection pipelines, and real-time dashboards.
- **Grassroots Tech Support:** Direct tech problem solving, institutional automation, and donor reporting systems.
- **Social Impact Acceleration:** Ensuring social development teams spend less time on paperwork and more time in communities.

---

## 🚀 Technology Stack
- **Frontend:** React 19 + TypeScript + Vite + Tailwind CSS
- **Icons & Motion:** Lucide React, Motion
- **Database & Auth:** Supabase / Firestore with offline fallback store
- **Communications:** Automated transactional notifications & multi-tier admin control

---

## 📦 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Seva479/seva-portal.git

# Navigate to project directory
cd seva-portal

# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 🏛️ Administrative Portal
The portal features a dedicated, secured administration cockpit with role-based access control for:
- Reviewing grassroot NGO support applications
- Managing community inquiries
- Scheduling field visits & strategy consultations
- Managing active programme projects & tech deployments
